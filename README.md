# 星星钱罐

给孩子使用的零花钱与习惯养成应用，采用单页 HTML，可直接在浏览器或主屏幕中运行。

## 功能

- 记录和修改零花钱，自动生成收支账单
- 中文阅读、英文阅读、按时入睡等每日奖励任务
- 晚睡、摸头发走神等温柔提醒
- 自定义奖惩规则、暂停或修改每日任务
- 孩子名字、头像和攒钱目标
- 愿望清单、价格、进度和愿望实现记录
- 星光等级、连续打卡、动画和音效反馈
- iPad、手机和桌面自适应布局

## 本地使用

直接用浏览器打开 `index.html` 即可。数据保存在当前浏览器的本地存储中。

## 部署

仓库包含 `render.yaml`，可在 Render 中作为静态站点部署。发布目录为仓库根目录，访问任意路径时返回 `index.html`。
